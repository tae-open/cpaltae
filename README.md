# 노무법인 태의 · 4대보험 신청서 시스템

직원 전용 4대보험 신청서 작성 시스템입니다.

- **화면**은 GitHub Pages에 올립니다(무료).
- **로그인, 계정, 작성 이력**은 구글 시트에 붙인 Apps Script가 맡습니다(무료).
- **PDF 작성**은 직원의 브라우저 안에서만 처리됩니다. 신청서 PDF와 주민등록번호 전체는 어디에도 전송되거나 저장되지 않습니다.

```
GitHub Pages (index.html)  ──로그인·이력 기록──▶  Apps Script 웹 앱  ──▶  구글 시트 ('계정', '이력')
        │
        └─ PDF 작성은 브라우저 안에서 처리 (pdf.js, pdf-lib, 한글 글꼴)
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 로그인, 신청서 작성, 내 작성 이력, 계정 관리, 전체 이력 화면 |
| `config.js` | Apps Script 웹 앱 주소 **(설치할 때 직접 넣는 곳)** |
| `assets/tool.js` | 신청서 PDF 작성 기능 |
| `assets/app.js` | 로그인, 화면 전환, 계정 관리 |
| `assets/common.js` | 서버 연결 도우미 |
| `assets/style.css` | 화면 디자인 |
| `assets/NotoSansKR-Regular.ttf` | PDF에 넣는 한글 글꼴 (한글 11,172자, 영문, 숫자, 기호) |
| `assets/sample.pdf` | 시험용 예시 신청서 |
| `apps-script/Code.gs` | 구글 Apps Script 서버 코드 **(GitHub에는 올라가지만 실행은 구글에서)** |

## 설치 방법 (처음 한 번, 약 15분)

### 1단계 · 구글 시트와 Apps Script 만들기

1. [Google 시트](https://sheets.google.com)에서 새 스프레드시트를 만듭니다. 이름 예: `태의 4대보험 시스템`
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 위쪽 함수 선택 칸에서 **`setup`**을 고르고 **실행**을 누릅니다.
   - 처음에는 권한 승인 창이 뜹니다. 본인 구글 계정을 선택한 뒤 **고급 → (안전하지 않은 페이지로) 이동 → 허용**을 누르세요. 직접 만든 스크립트라 나오는 안내입니다.
5. 아래 **실행 로그**에 관리자 계정이 표시됩니다.
   ```
   아이디: admin
   임시 비밀번호: Ab3cD7eFgh
   ```
   이 임시 비밀번호를 적어 두세요. 시트에 `계정`, `이력` 탭이 생긴 것도 확인합니다.

### 2단계 · 웹 앱으로 배포하기

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.
   - **다음 사용자 인증 정보로 실행:** 나
   - **액세스 권한이 있는 사용자:** **모든 사용자**
4. **배포**를 누르고 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> "모든 사용자"로 해야 직원 브라우저에서 접속할 수 있습니다. 대신 Apps Script가 아이디·비밀번호를 직접 확인하므로, 로그인하지 않은 사람은 계정이나 이력을 볼 수 없습니다.

### 3단계 · 화면에 서버 주소 넣기

`config.js`를 열어 `API_URL`에 방금 복사한 주소를 넣습니다.

```js
window.TAEUI_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
  OFFICE_NAME: '노무법인 태의'
};
```

### 4단계 · GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 예: `taeui-4insurance`
2. 이 폴더의 파일을 모두 올립니다. 웹에서 **Add file → Upload files**로 끌어다 놓아도 됩니다.
3. 저장소의 **Settings → Pages**에서 **Branch: `main` / `/ (root)`**를 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<GitHub아이디>.github.io/taeui-4insurance/` 주소로 접속됩니다.

### 5단계 · 첫 로그인과 직원 등록

1. 접속해서 `admin`과 임시 비밀번호로 로그인하면, 본인 비밀번호로 바꾸는 화면이 나옵니다.
2. **계정 관리** 탭에서 직원 아이디와 이름을 넣고 **계정 등록**을 누릅니다.
3. 화면에 나온 **임시 비밀번호**를 직원에게 전달합니다. 직원은 첫 로그인 때 본인 비밀번호로 바꿉니다.

## 사용 중 자주 하는 일

| 하고 싶은 일 | 방법 |
|---|---|
| 직원 비밀번호를 잊었을 때 | 계정 관리 → **비밀번호 초기화** → 새 임시 비밀번호 전달 |
| 퇴사자 처리 | 계정 관리 → **사용 중지** (기록은 남고 로그인만 막힘) |
| 다른 사람에게 관리자 권한 주기 | 계정 관리 → **관리자로** |
| 관리자(admin) 비밀번호를 잊었을 때 | Apps Script 편집기에서 `resetAdminPassword` 함수 실행 → 실행 로그에 새 임시 비밀번호 |
| 전체 작성 기록 보기, 엑셀로 받기 | 구글 시트 `이력` 탭 (파일 → 다운로드 → .xlsx) |

버튼은 실수를 막기 위해 **두 번 눌러야** 실행됩니다.

## Code.gs를 고친 뒤에는

Apps Script에서 코드를 바꾸면 **배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. 이렇게 하면 URL은 그대로라 `config.js`를 바꿀 필요가 없습니다. **새 배포**를 누르면 URL이 바뀌니 주의하세요.

## 보안 메모

- 비밀번호는 시트에 **해시(복원할 수 없는 값)로만** 저장됩니다. 관리자도 원래 비밀번호를 볼 수 없습니다.
- 비밀번호를 5번 틀리면 그 아이디는 15분 동안 잠깁니다.
- 로그인은 6시간 유지되고, 브라우저 탭을 닫으면 끝납니다.
- 작성 이력에는 주민등록번호를 `850315-2******`처럼 **뒷자리를 가려서** 기록합니다.
- 구글 시트는 **공유하지 마세요**(본인만 소유). 시트에 접근할 수 있는 사람은 이력 전체를 볼 수 있습니다.
- GitHub 저장소가 공개여도 화면 코드만 보일 뿐, 계정과 이력은 구글 시트에 있어 보이지 않습니다. 작성 화면은 로그인한 뒤에만 보이지만 이 잠금은 브라우저 쪽에서 하는 것이라, 코드를 다룰 줄 아는 사람은 우회해서 PDF 작성 기능을 쓸 수 있습니다. 우회해도 계정과 이력에는 접근할 수 없습니다.

## 한계

- 스캔한 이미지 PDF는 칸을 자동으로 찾지 못합니다. **위치 지정**으로 직접 놓아야 하고, 원래 적힌 값도 지워지지 않습니다.
- 한자는 PDF에 넣을 수 없습니다(한글, 영문, 숫자, 기본 기호만).
- 신청서별로 맞춘 칸 위치는 각자 브라우저에 기억됩니다. 다른 컴퓨터에서는 처음 한 번 다시 맞춰야 합니다.
