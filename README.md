# 노무법인 태의 · 4대보험 청구 시스템 (웹 버전)

컴퓨터에서 돌리던 Python 프로그램(tae-pdf-system)의 서류 작성 기능을 웹으로 옮긴 버전입니다.

- **화면**은 GitHub Pages에 올립니다(무료).
- **로그인, 계정, 발급 기록**은 구글 시트에 붙인 Apps Script가 맡습니다(무료).
- **서류 작성**은 직원의 브라우저 안에서만 처리됩니다. 주민등록번호, 신분증 사진, 만든 PDF는 서버로 보내지 않습니다.

```
GitHub Pages (index.html)  ──로그인·발급 기록──▶  Apps Script 웹 앱  ──▶  구글 시트 ('계정', '발급기록')
        │
        └─ 서류 6종 작성·막도장·신분증 합치기는 브라우저 안에서 처리 (pdf-lib, pdf.js)
```

## 지금 되는 것

| 기능 | 내용 |
|---|---|
| 1페이지 기본정보 입력 | 위임자(성명·휴대폰·주민번호·주소), 수임자(성명·휴대폰·주민번호), 발급 날짜, 신분증(JPG·PNG, 10MB, 메타데이터 제거) |
| 서류 자동 작성 | 1 국민연금 증명원 발급 신청서, 3 소득금액증명원 발급 신청서, 4 소득금액증명원 발급 위임장, 5 고용보험 발급 신청서, 6 고용보험 발급 위임장, 7 일용근로소득증명원 발급 신청서 및 위임장 |
| 막도장 | 위임자·수임자 이름으로 자동 생성, 원래 프로그램과 같은 위치·크기(14.4mm, 좁은 칸 예외 동일) |
| 2페이지 | 국민연금공단 / 세무서 / 근로복지공단 탭, 미리보기 = 다운로드 파일, 신분증 없으면 다운로드 막음 |
| 생성 후 검사 | 칸마다 써 넣은 글자를 다시 읽어 입력과 다르면 내보내지 않음, 고정값·같은 값 칸·도장 크기 확인, 서식 파일 지문 확인 |
| 30분 보관 | 신분증을 올린 때부터 30분 뒤, 로그아웃, 새 서류 작성 때 입력값·신분증·PDF를 지움 |
| 발급 기록 | 누가·언제·어떤 서류·파일 지문(SHA-256)만 기록. 개인정보는 기록하지 않음 |
| 계정 | 관리자가 직원 계정 등록, 비밀번호 초기화, 권한, 사용 중지 |

**아직 안 되는 것(원래 프로그램에는 있음):** 국민연금 관할지사·팩스번호 조회, 팩스 전송, 국민연금 지사 관리 화면, "직원은 본인 비밀번호 변경 불가" 정책.

## 원래 프로그램과 다른 점

- **PDF 글꼴:** 원래는 맑은 고딕, 웹 버전은 Noto Sans KR입니다(맑은 고딕은 웹에 올려 배포할 수 없는 글꼴). 칸 맞춤·줄바꿈 규칙은 같습니다.
- **막도장 글꼴:** 직원 컴퓨터에 맑은 고딕이 있으면(윈도우) 맑은 고딕 굵게, 없으면 Noto Sans KR 굵게로 그립니다.
- **임시 보관:** 원래는 서버에 암호화해 30분 보관, 웹 버전은 서버를 거치지 않고 브라우저 메모리에만 둡니다.
- **로그인 보안:** 원래 프로그램(Argon2, CSRF 방어, 접속지 차단)보다 단순합니다. 시트에는 계정과 발급 기록만 있고 개인정보는 없습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 로그인, 4대보험 청구(1·2페이지), 발급 기록, 계정 관리 화면 |
| `config.js` | Apps Script 웹 앱 주소 **(설치할 때 직접 넣는 곳)** |
| `assets/forms.js` | 서류 자동 작성, 막도장, 날인 위치, 기관별 묶음, 생성 후 검사 |
| `assets/issue.js` | 1페이지·2페이지 화면 |
| `assets/app.js`, `assets/common.js` | 로그인, 계정 관리, 서버 연결 |
| `assets/forms/` | 빈 서식 PDF 6개와 `specs.json`(칸 좌표·날인칸·도장이 피할 글자 위치) |
| `assets/NotoSansKR-Regular.ttf` | PDF에 넣는 글꼴(한글 11,172자, 한자, 영문, 숫자, 기호) |
| `apps-script/Code.gs` | 구글 Apps Script 서버 코드 |
| `tools/export_specs.py` | 서식을 바꿨을 때 원래 Python 프로그램에서 `assets/forms/`를 다시 만드는 도구 |

## 이미 설치했다면: 이번 업데이트 반영 방법

1. **Apps Script 코드 바꾸기:** 구글 시트 → 확장 프로그램 → Apps Script에서 `Code.gs` 내용을 모두 지우고 새 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
2. **새 버전으로 다시 배포:** 배포 → 배포 관리 → 연필(수정) → 버전: **새 버전** → 배포. (주소가 그대로라 `config.js`는 바꾸지 않아도 됩니다.)
3. **GitHub에 파일 올리기:** 저장소의 업로드 화면에서 이 폴더의 파일과 폴더를 전부 끌어다 놓고 Commit changes를 누릅니다. `config.js`는 이미 주소를 넣어 둔 것을 올리세요.
4. 1~3분 뒤 사이트에서 **Ctrl+F5**를 누릅니다.

발급 기록은 시트의 새 탭 `발급기록`에 쌓입니다(처음 내려받을 때 자동으로 생김). 예전 `이력` 탭은 지워도 됩니다.

## 설치 방법 (처음 한 번, 약 15분)

### 1단계 · 구글 시트와 Apps Script 만들기

1. [Google 시트](https://sheets.google.com)에서 새 스프레드시트를 만듭니다. 이름 예: `태의 4대보험 시스템`
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 받은 압축 파일 안의 **apps-script 폴더 → Code.gs 파일**을 메모장으로 열어 전체 내용(Ctrl+A → Ctrl+C)을 복사해 붙여 넣은 뒤 저장합니다.
4. 위쪽 함수 선택 칸에서 **setup** 을 고르고 **실행**을 누릅니다.
   - 처음에는 권한 승인 창이 뜹니다. 본인 구글 계정을 선택한 뒤 **고급 → (안전하지 않은 페이지로) 이동 → 허용**을 누르세요. 직접 만든 스크립트라 나오는 안내입니다.
5. 아래 **실행 로그**에 관리자 계정이 표시됩니다. (아래 비밀번호는 예시이고, 실제로는 실행할 때마다 다르게 나와요)
   ```
   아이디: admin
   임시 비밀번호: Ab3cD7eFgh
   ```
   이 임시 비밀번호를 적어 두세요. 시트에 `계정`, `발급기록` 탭이 생긴 것도 확인합니다.

### 2단계 · 웹 앱으로 배포하기

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.
   - **다음 사용자 인증 정보로 실행:** 나
   - **액세스 권한이 있는 사용자:** **모든 사용자**
4. **배포**를 누르고 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> "모든 사용자"로 해야 직원 브라우저에서 접속할 수 있습니다. 대신 Apps Script가 아이디·비밀번호를 직접 확인하므로, 로그인하지 않은 사람은 계정이나 발급 기록을 볼 수 없습니다.

### 3단계 · 화면에 서버 주소 넣기

`config.js`를 열어 `API_URL`에 방금 복사한 주소를 넣습니다.

```js
window.TAEUI_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
  OFFICE_NAME: '노무법인 태의'
};
```

### 4단계 · GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 예: `taeui-4insurance`
2. 이 폴더의 파일을 모두 올립니다. 웹에서 **Add file → Upload files**로 끌어다 놓아도 됩니다.
3. 저장소의 **Settings → Pages**에서 **Branch: `main` / `/ (root)`**를 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<GitHub아이디>.github.io/taeui-4insurance/` 주소로 접속됩니다.

### 5단계 · 첫 로그인과 공용 계정 만들기

계정은 두 종류로 씁니다.

| 계정 | 쓰는 사람 | 비밀번호 |
|---|---|---|
| `admin` (관리자) | 대표 노무사 | 본인이 정하고 바꿀 수 있음 |
| `tae1` (직원) | 모든 직원이 함께 사용 | **관리자만** 정하고 바꿀 수 있음 |

1. 사이트에 `admin`과 임시 비밀번호로 로그인하면, 관리자 비밀번호를 새로 정하는 화면이 나옵니다.
2. **계정 관리** 탭에서 아이디 `tae1`, 이름 `직원 공용`, 역할 `직원`, 비밀번호(영문+숫자 8자 이상)를 넣고 **계정 등록**을 누릅니다.
3. 직원들에게 `tae1`과 그 비밀번호를 알려 줍니다. 여러 명이 동시에 로그인해도 됩니다.

## 사용 중 자주 하는 일

| 하고 싶은 일 | 방법 |
|---|---|
| 공용 계정(tae1) 비밀번호 바꾸기 | 계정 관리 → tae1 줄의 **비밀번호 지정** → 새 비밀번호와 관리자 비밀번호 입력. tae1로 로그인해 있던 모든 화면이 로그아웃됨 |
| 퇴사자가 생겨 공용 비밀번호를 바꿔야 할 때 | 위와 같이 tae1 비밀번호를 바꾸고 남은 직원에게만 알려 줌 |
| 공용 계정을 잠시 막기 | 계정 관리 → **사용 중지** (기록은 남고 로그인만 막힘) |
| 관리자 비밀번호 바꾸기 | 오른쪽 위 **비밀번호 변경** |
| 관리자(admin) 비밀번호를 잊었을 때 | Apps Script 편집기에서 `resetAdminPassword` 함수 실행 → 실행 로그에 새 임시 비밀번호 |
| 전체 발급 기록 보기, 엑셀로 받기 | 구글 시트 `발급기록` 탭 (파일 → 다운로드 → .xlsx) |

> 공용 계정은 누군가 비밀번호를 5번 틀리면 **모든 직원이 15분 동안** 로그인할 수 없습니다.

버튼은 실수를 막기 위해 **두 번 눌러야** 실행됩니다.

## Code.gs를 고친 뒤에는

Apps Script에서 코드를 바꾸면 **배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. 이렇게 하면 URL은 그대로라 `config.js`를 바꿀 필요가 없습니다. **새 배포**를 누르면 URL이 바뀌니 주의하세요.

## 보안 메모

- 비밀번호는 시트에 **해시(복원할 수 없는 값)로만** 저장됩니다. 관리자도 원래 비밀번호를 볼 수 없습니다.
- 비밀번호를 5번 틀리면 그 아이디는 15분 동안 잠깁니다.
- 로그인은 6시간 유지되고, 브라우저 탭을 닫으면 끝납니다.
- 발급 기록에는 직원·시각·서류 종류·파일 지문만 남고, 입력한 개인정보는 기록하지 않습니다.
- 구글 시트는 **공유하지 마세요**(본인만 소유). 시트에 접근할 수 있는 사람은 계정 목록과 발급 기록을 볼 수 있습니다.
- GitHub 저장소가 공개여도 화면 코드만 보일 뿐, 계정과 발급 기록은 구글 시트에 있어 보이지 않습니다. 빈 서식 PDF는 공개되지만 개인정보가 없는 빈 양식입니다. 작성 화면은 로그인한 뒤에만 보이지만 이 잠금은 브라우저 쪽에서 하는 것이라, 코드를 다룰 줄 아는 사람은 우회해서 서류 작성 기능을 쓸 수 있습니다. 우회해도 계정과 발급 기록에는 접근할 수 없습니다.

## 한계

- 서류 칸에 들어갈 내용이 너무 길면(예: 주소 70자 이상) 원래 프로그램처럼 생성을 멈추고 안내합니다.
- 서식 PDF를 바꾸려면 원래 Python 프로그램에서 `tools/export_specs.py`로 `assets/forms/`를 다시 만들어야 합니다.
- 인터넷 익스플로러는 지원하지 않습니다. 크롬이나 엣지를 쓰세요.
